# Traditional checkers (generic software-correctness sanitizers)

Inactive unless `SCIBENCH_TRADITIONAL_LOG` names a writable file. Hooks are called from the instrumented modules.

Every checker is skipped when any of its arguments holds a finite number larger than 1e100 in magnitude (float64 overflow range, not a defect); preconditions below may be stricter.

- **AP-SWE-001** `binom_conf_interval` (astropy/stats/funcs.py) — output finiteness. Precondition: k, n pass the function's own validation. Invariant: every entry of the returned interval is finite. Observed immediately before returning conf_interval. Alarm: any entry is NaN or inf.
- **AP-SWE-002** `kuiper_false_positive_probability` (astropy/stats/funcs.py) — denominator nonzero before division. Precondition: any call that passes the 0 <= D <= 2 check. Invariant: N is nonzero before it is used as a divisor in `D < 2.0 / N`. Observed immediately before `if D < 2.0 / N`. Alarm: N == 0.
- **AP-SWE-003** `biweight_location` (astropy/stats/biweight.py) — output finiteness. Precondition: all data finite with |x| < 1e150 and every MAD nonzero. Invariant: the location estimate is finite. Observed after `value` is computed, before the scalar/array return. Alarm: such data yields a non-finite value.
- **AP-SWE-004** `biweight_midvariance` (astropy/stats/biweight.py) — denominator nonzero before division. Precondition: any call past the scalar MAD == 0 early return. Invariant: f2 is nonzero wherever MAD is nonzero. Observed immediately before `value = n * f1 / f2`. Alarm: f2 == 0 where MAD != 0.
- **AP-SWE-005** `biweight_midcovariance` (astropy/stats/biweight.py) — denominator nonzero before division. Precondition: any call reaching the matrix quotient. Invariant: denominator_matrix is nonzero for all rows/columns whose MAD is nonzero. Observed immediately before `numerator_matrix / denominator_matrix`. Alarm: a zero in denominator_matrix among MAD != 0 rows.
- **AP-SWE-006** `biweight_midcorrelation` (astropy/stats/biweight.py) — denominator nonzero before division. Precondition: x and y finite and non-constant (a constant variable has an undefined correlation). Invariant: the radicand bicorr[0,0]*bicorr[1,1] is strictly positive. Observed immediately before the final division. Alarm: radicand <= 0 or NaN.
- **AP-SWE-007** `_components` (astropy/stats/circstats.py) — denominator nonzero before division. Precondition: weights broadcast to data.shape; slices whose weights are all zero are excluded. Invariant: np.sum(weights, axis) is nonzero. Observed immediately before the C and S quotients. Alarm: sum(weights, axis) == 0 while some weight is nonzero.
- **AP-SWE-008** `circcorrcoef` (astropy/stats/circstats.py) — denominator nonzero before division. Precondition: alpha and beta finite and non-constant, with ptp(alpha)*ptp(beta) > 1e-100 (a constant sample has an undefined correlation; smaller spreads underflow the sum-of-squares product, a floating-point limit). Invariant: the product of the two sums of squares is strictly positive. Observed immediately before the rho quotient. Alarm: product of sums of squares <= 0 or NaN.
- **AP-SWE-009** `RegularEvents.fitness` (astropy/stats/bayesian_blocks.py) — denominator nonzero before division. Precondition: any call to fitness. Invariant: M_k = T_k / dt is nonzero for every block. Observed immediately before `N_k / M_k`. Alarm: any M_k == 0.
- **AP-SWE-010** `scott_bin_width` (astropy/stats/histogram.py) — denominator nonzero before division. Precondition: return_bins is requested (the division is only evaluated there). Invariant: dx is nonzero. Observed immediately before `(max - min) / dx`. Alarm: dx == 0.
- **AP-SWE-011** `freedman_bin_width` (astropy/stats/histogram.py) — denominator nonzero before division. Precondition: return_bins is requested; zero IQR on non-constant data is excluded (documented ValueError, astropy #7125). Invariant: dx is nonzero. Observed immediately before `(dmax - dmin) / dx`. Alarm: dx == 0 and max - min == 0 (constant data, 0/0).
- **AP-SWE-012** `akaike_info_criterion` (astropy/stats/info_theory.py) — denominator nonzero before division. Precondition: any call. Invariant: n_params is nonzero. Observed immediately before `n_samples / float(n_params)`. Alarm: n_params == 0.
- **AP-SWE-013** `bayesian_info_criterion_lsq` (astropy/stats/info_theory.py) — function domain. Precondition: ssr finite (a non-finite ssr from overflowing residuals is a floating-point limit). Invariant: ssr / n_samples is nonnegative and finite (ssr == 0 is a defined limit). Observed immediately before `np.log(ssr / n_samples)`. Alarm: argument < 0, NaN or inf.
- **AP-SWE-014** `signal_to_noise_oir_ccd` (astropy/stats/funcs.py) — denominator nonzero before division. Precondition: any call (zero signal over zero noise, i.e. zero exposure, is excluded; infinite noise from overflow is a floating-point limit). Invariant: noise is nonzero and not NaN. Observed immediately before `signal / noise`. Alarm: noise == 0 with signal != 0, or noise is NaN.
- **AP-SWE-015** `convolve_fft` (astropy/convolution/convolve.py) — array shape invariant. Precondition: crop=True. Invariant: the returned array has the input array's shape. Observed immediately before the return. Alarm: cropped output shape != input shape.
- **AP-SWE-016** `convolve` (astropy/convolution/convolve.py) — output finiteness. Precondition: finite array and finite kernel with sum|array| * sum|kernel| < 1e300, no mask and no masked-array input (a fully masked window gives NaN by documented design). Invariant: the result is finite. Observed before the dtype cast and return. Alarm: such inputs give a non-finite result.
- **AP-SWE-017** `discretize_oversample_1D` (astropy/convolution/utils.py) — array shape invariant. Precondition: any call. Invariant: x.size is divisible by factor. Observed immediately before `np.reshape(values, (x.size // factor, factor))`. Alarm: x.size % factor != 0.
- **AP-SWE-019** `HistEqStretch.__init__` (astropy/visualization/stretch.py) — denominator nonzero before division. Precondition: any call. Invariant: vmax != vmin. Observed immediately before `(data - vmin) / (vmax - vmin)`. Alarm: vmax == vmin.
- **AP-SWE-020** `ZScaleInterval.get_limits` (astropy/visualization/interval.py) — denominator nonzero before division. Precondition: any call. Invariant: n_samples is nonzero. Observed immediately before `values.size / self.n_samples`. Alarm: n_samples == 0.
- **AP-SWE-021** `LombScargle.autofrequency` (astropy/timeseries/periodograms/lombscargle/core.py) — denominator nonzero before division. Precondition: any call. Invariant: 1/baseline/samples_per_peak is finite and nonzero. Observed immediately before `df = 1.0 / baseline / samples_per_peak`. Alarm: baseline or samples_per_peak zero, or df non-finite/zero.
- **AP-SWE-022** `LombScargle.offset` (astropy/timeseries/periodograms/lombscargle/core.py) — denominator nonzero before division. Precondition: center_data is True and every uncertainty in [1e-100, 1e100]. Invariant: w.sum() is finite and nonzero. Observed immediately before `np.dot(y, w) / w.sum()`. Alarm: w.sum() == 0 or non-finite.
- **AP-SWE-023** `fap_bootstrap` (astropy/timeseries/periodograms/lombscargle/_statistics.py) — denominator nonzero before division. Precondition: any call. Invariant: len(pmax) is nonzero. Observed immediately before `searchsorted(pmax, Z) / len(pmax)`. Alarm: len(pmax) == 0.
- **AP-SWE-024** `BoxLeastSquares.model` (astropy/timeseries/periodograms/bls/core.py) — denominator nonzero before division. Precondition: any call. Invariant: sum of ivar in and out of transit is nonzero. Observed immediately before the in/out weighted means. Alarm: either weight sum == 0.
- **AP-SWE-025** `BoxLeastSquares.compute_stats._compute_depth` (astropy/timeseries/periodograms/bls/core.py) — denominator nonzero before division. Precondition: the mask m is non-empty and every uncertainty in [1e-100, 1e100]. Invariant: sum(ivar[m]) is nonzero. Observed immediately before `1.0 / np.sum(ivar[m])`. Alarm: sum(ivar[m]) == 0.
- **AP-SWE-026** `_weighted_mean` (astropy/timeseries/periodograms/lombscargle/_statistics.py) — denominator nonzero before division. Precondition: dy is not None and every uncertainty in [1e-100, 1e100]. Invariant: weighted sum of ones is finite and nonzero. Observed immediately before the quotient. Alarm: denominator == 0 or non-finite.
- **AP-SWE-028** `from_variance_for_mean` (astropy/nddata/nduncertainty.py) — denominator nonzero before division. Precondition: any call. Invariant: count of unmasked elements is nonzero. Observed immediately before `np.sqrt(np.ma.sum(x, axis)) / denom`. Alarm: denom == 0.
- **AP-SWE-029** `Cutout2D.__init__` (astropy/nddata/utils.py) — denominator nonzero before division. Precondition: size has angular units. Invariant: the axis pixel scale is nonzero. Observed immediately before `side / pixel_scales[axis]`. Alarm: pixel_scales[axis] == 0.
- **AP-SWE-030** `PowerLaw1D.evaluate` (astropy/modeling/powerlaws.py) — denominator nonzero before division. Precondition: any call. Invariant: x_0 is nonzero. Observed immediately before `x / x_0`. Alarm: x_0 == 0.
- **AP-SWE-031** `ArcSine1D.evaluate` (astropy/modeling/functional_models.py) — denominator nonzero before division. Precondition: any call. Invariant: amplitude is nonzero. Observed immediately before `x / amplitude`. Alarm: amplitude == 0.
- **AP-SWE-032** `_apply_relativistic_doppler_shift` (astropy/coordinates/spectral_coordinate.py) — function domain. Precondition: any call. Invariant: (1+beta)/(1-beta) is finite and nonnegative. Observed immediately before `np.sqrt((1.0 + beta) / (1.0 - beta))`. Alarm: radicand non-finite or negative.
- **AP-SWE-033** `BaseSphericalDifferential._get_d_lon / _d_lon` (astropy/coordinates/representation/spherical.py) — denominator nonzero before division. Precondition: any call. Invariant: |cos(lat)| is above machine epsilon. Observed immediately before `d_lon_coslat / np.cos(lat)`. Alarm: |cos(lat)| < eps.
- **AP-SWE-035** `LambdaCDM._flat_age` (astropy/cosmology/_src/flrw/lambdacdm.py) — denominator nonzero before division. Precondition: any call. Invariant: 1 - Om0 is nonzero. Observed immediately before `... / np.emath.sqrt(1 - self.Om0)`. Alarm: Om0 == 1.
